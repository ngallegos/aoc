Bitmask sets and Dynamic Programming over subsets

Written lesson

This lesson combines two ideas: dynamic programming, which means solving small versions of a problem once and reusing the answers, and bitmasks, which store a set of items in a single number. Use them together when you need to pick or order a small group of things and trying every order is too slow.

What is dynamic programming (DP)?

Suppose you can climb 1 or 2 stairs at a time. How many ways are there to reach step 5? Your last move came from step 4 or step 3, so ways(5) = ways(4) + ways(3). Instead of working out the same smaller answers repeatedly, start small and save each one: 

const ways = [1, 1]; // step 0 and step 1
for (let step = 2; step <= 5; step++) {
  ways[step] = ways[step - 1] + ways[step - 2];
}
// ways is now [1, 1, 2, 3, 5, 8]

Four questions guide most DP solutions:

  • State: what does one saved answer mean? (ways[step])
  • Base cases: which answers do you already know? (steps 0 and 1)
  • Transition: how is an answer built from smaller ones? (add the previous two)
  • Result: where is the final answer? (ways[5])

DP over subsets

Often the state is not a step number but a set of items, such as the tasks already taken. If best[set] is the cheapest way to handle those items, then {0, 2} can be built from {0} by adding 2, or from {2} by adding 0. Keep the cheaper one. After that, the order no longer matters, so many orders collapse into one entry.

If the next choice also depends on the item used last, add it to the state: best[set][last].

A set stored as an int

To write best[set] in code, the set has to be a number. An integer is a row of bits, so let bit i be 1 when item i is in the set. Bits are numbered from the right, starting at 0. Items 0, 1, 2, 3 are worth 1, 2, 4, 8, and a set is the sum of its members.

  • 1 << i is a number with only bit i on.
  • set | (1 << i) adds item i.
  • set & (1 << i) is non-zero when item i is in the set.
  • set & ~(1 << i) removes item i.
  • (1 << n) - 1 is the set of all n items.
